Untuk orang yang belum pernah memakai Python. Ikuti urutan langkahnya.

Panduan Pemasangan FASIH Bulk

Dua file yang bisa diklik dua kali untuk me-reject atau me-approve banyak assignment sekaligus di FASIH SM, tanpa klik satu per satu.

FileFungsi
fasih_bulk.pyReject massal (juga bisa Cek status)
fasih_approve_pengawas.pyApprove massal khusus Pengawas (juga bisa Cek status)
Sebelum mulai: pastikan Windows 10/11 tersambung internet, punya akun FASIH dengan role Pengawas (PML) yang bisa login di Chrome/Edge, dan sudah punya ketiga file: fasih_bulk.py, fasih_approve_pengawas.py, dan contoh data.xlsx.

1Pasang Python (sekali saja per PC)

Python adalah program "mesin" yang menjalankan file .py. Pasang sekali, lalu tidak perlu dibuka lagi.

  1. Buka python.org/downloads.
  2. Klik tombol kuning Download Python 3.x.x.
  3. Buka file yang terunduh (folder Downloads).
  4. Centang kotak paling bawah: "Add python.exe to PATH" — langkah yang paling sering terlewat.
  5. Klik Install Now, lalu Yes jika Windows bertanya izin.
  6. Tunggu sampai Setup was successful, klik Close.

Cek apakah berhasil

  1. Tekan Windows + R, ketik cmd, Enter.
  2. Ketik: py --version
  3. Muncul Python 3.12.x berarti berhasil.

2Buat folder kerja REJECT di drive D

  1. Buka File Explorer → Data (D:).
  2. Klik kanan → New → Folder → beri nama REJECT.
  3. Salin fasih_bulk.py dan fasih_approve_pengawas.py ke D:\REJECT.

Tidak ada drive D? Boleh pakai drive lain, yang penting semua file ada dalam satu folder yang sama. Skrip otomatis bekerja di folder tempatnya berada.

3Pasang dua pustaka tambahan (sekali saja per PC)

  1. Buka folder D:\REJECT.
  2. Klik kotak alamat di atas, hapus isinya, ketik cmd, Enter — jendela hitam terbuka langsung di folder itu.
  3. Ketik lalu Enter: 
    py -m pip install requests openpyxl
  4. Tunggu sampai muncul Successfully installed ....

Butuh internet. Tulisan kuning soal "new release of pip" boleh diabaikan.

4Siapkan daftar assignment di data.xlsx

  1. Buka Excel, buat file baru.
  2. Sel A1 diisi judul: Link Fasih
  3. Mulai A2 ke bawah, tempel link assignment, satu link per baris.
  4. Simpan sebagai data.xlsx di folder D:\REJECT, tutup Excel.
Link Fasih
https://fasih-sm.bps.go.id/app/assignment-detail/37c3ba8c-2cfe-4aac-b09a-e392fd313080
https://fasih-sm.bps.go.id/app/assignment-detail/25170152-c244-479a-9f26-a4ce93b4fe3f

Kolom lain di Excel tidak masalah — hanya kolom bernama Link Fasih yang dibaca. Isi hanya assignment yang memang mau diproses; reject massal tidak mudah dibatalkan. Link ganda otomatis dibuang.

5Ambil cookie dari browser

Cookie adalah tanda pengenal login akunmu. Skrip meminjamnya supaya bekerja sebagai kamu.

  1. Login ke fasih-sm.bps.go.id dengan akun Pengawas.
  2. Buka survei SENSUS EKONOMI 2026 → menu Data.
  3. Tekan F12 → tab Network → filter Fetch/XHR.
  4. Tekan F5 untuk memuat ulang.
  5. Klik salah satu baris fasih-sm berstatus 200.
  6. Tab Headers → gulir ke Request Headers → cari Cookie.
  7. Klik tiga kali nilainya, Ctrl+C.
  8. Kembali ke jendela hitam skrip (tulisan Cookie baru>), tempel, Enter.
Cookie = kunci login akunmu. Jangan kirim ke siapa pun, jangan di-screenshot lalu dibagikan. Skrip menyimpannya di cookie.txt di folder REJECT. Hapus file itu kalau PC dipakai bersama.

6Jalankan skrip

Klik dua kali fasih_bulk.py untuk Reject, atau fasih_approve_pengawas.py untuk Approve. Jendela hitam bertanya beberapa hal — tekan Enter untuk pilihan bawaan:

PertanyaanJawab
Pilih aksi1 untuk Cek status, atau Enter untuk aksi utama
File daftar IDEnter (otomatis data.xlsx)
Survey Period IDEnter (sudah terisi periode PENDATAAN)
Mode dry-runy untuk hanya melihat rencana, atau Enter untuk langsung jalan
Cookie baruTempel cookie (lihat Langkah 5)
Ketik YAYA lalu Enter untuk benar-benar mengirim

Urutan aman

  1. Cek status dulu (pilih 1) — hanya membaca, tidak mengubah apa pun.
  2. Coba 1-2 assignment dulu di data.xlsx sementara, periksa hasilnya di FASIH.
  3. Kalau benar, ganti dengan daftar lengkap dan jalankan untuk semuanya.

Yang dilewati otomatis: Reject melewati status REJECTED/SUBMITTED; Approve melewati status APPROVED/REJECTED; keduanya melewati assignment yang tidak ditemukan.

7Baca hasilnya

Ringkasan muncul di layar, dan rincian tiap assignment tersimpan di log_reject_....csv atau log_approve_....csv di folder REJECT.

StatusArtinya
BerhasilAksi sudah dijalankan
DilewatiSengaja tidak diproses; alasan ada di kolom keterangan
GagalDitolak server atau ada gangguan; baca kolom keterangan

Untuk mengulang yang Gagal (ganti nama file log dan periode sesuai keperluan):

py fasih_bulk.py reject --failed-from NAMA_FILE_LOG.csv --period fd68e454-ba45-4b85-8205-f3bf777ded24
